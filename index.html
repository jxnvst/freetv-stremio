FreeTV Live for Stremio

Free US live TV — 24 categories, browser-playable, online only, multiple streams per channel.

Install in Stremio Configure first
No install button or not signed in? Open the Stremio app (PC, phone, LG, TCL) → Addons → Install from URL → paste: https://jxnvst.github.io/freetv-stremio/manifest.json That manifest.json is JSON on purpose — install it inside Stremio, don't open it in a browser. Install once while logged in and it syncs to all your devices.
