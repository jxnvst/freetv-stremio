# FreeTV Live (Stremio addon)
Configurable Stremio addon mirroring freetv-live.vercel.app — US channels from
FreeTV / iptv-org, catalog/meta/stream resources, `freetv:` id prefix, configure page.
Regenerate with: `python3 build.py` (needs `channels_US.json` + `details/` in this dir).
Hosted on GitHub Pages: https://jxnvst.github.io/freetv-stremio/
